# Liantes Quiz Metalero 🤘

Concurso de preguntas sobre rock, heavy metal y la Associació Liantes Metaleros (Badalona).

- `index.html` — el juego
- `preguntas.csv` — banco de preguntas (pregunta, correcta, incorrecta1-3, categoria, dificultad, activa opcional)
- `supabase.sql` — base de datos del Hall of Fame compartido

Para añadir o cambiar preguntas basta con editar `preguntas.csv` (una fila por pregunta).
